# flu-seqneut-2026to2027

This repository will hold the data and analysis for the fourth installment of the Bloom lab's ongoing sequencing-based neutralization studies of the human neutralizing antibody landscape to seasonal influenza.

This project is currently a blank scaffold. Data, code, and results will be added here as the 2026-2027 study progresses.

## Past studies in this series

This project is the fourth installment in this series of studies. See each repository below for its own data, analysis, and associated paper:

- **flu-seqneut-2026**: <https://github.com/jbloomlab/flu-seqneut-2026>
- **flu-seqneut-2025to2026**: <https://github.com/jbloomlab/flu-seqneut-2025to2026>
- **flu-seqneut-2025**: <https://github.com/jbloomlab/flu-seqneut-2025>
